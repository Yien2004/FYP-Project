Staff Registration & Admin Approval

Flowchart tracking staff state validations and admin verification actions.

flowchart TD
    Start([Staff submits Registration Form]) --> CreateUser[Auth account created with approved=false]
    CreateUser --> PendingScreen[Staff attempts Login: Shows Warning Screen]
    
    %% Admin workflow branch
    AdminLogin([Admin logs in: admin@gmail.com]) --> AdminDashboard[Accesses Dashboard / Staff Accounts]
    AdminDashboard --> ReviewRequest{Review Staff Request}
    
    ReviewRequest -- Reject --> DeleteAuth[Delete Auth User account]
    DeleteAuth --> EndRejected([End: Registration Terminated])
    
    ReviewRequest -- Approve --> MergeMeta[Merge metadata: set approved=true]
    MergeMeta --> StaffLogin[Staff logs in again]
    StaffLogin --> AuthSuccess{Credentials Valid?}
    AuthSuccess -- No --> LoginError[Show Error]
    AuthSuccess -- Yes --> LoadStaffApp[Enter Staff Workspace]
    LoadStaffApp --> EndApproved([End: Session Active])

Patient Booking & Staff Triage

Flowchart tracking appointments from submission to approval matrix.

flowchart TD
    StartBooking([Patient logs in]) --> OpenBooking[Select Facility, Date, Time & Specialty]
    OpenBooking --> SubmitApt[Submit: Appointment Status set to Pending]
    
    StaffTriage([Staff logs in]) --> OpenMatrix[Open Patient Scheduling Matrix]
    OpenMatrix --> SelectApt[Select Pending Appointment]
    
    SelectApt --> Decision{Action: Triage Triage}
    
    Decision -- "Approve" --> SetApproved[Set Status to Approved]
    Decision -- "Reschedule" --> ChangeDateTime[Modify Date/Time: Set Status to Rescheduled]
    Decision -- "Reject" --> SetRejected[Set Status to Rejected]
    
    SetApproved --> SyncDB[Update Database & Notify Patient]
    ChangeDateTime --> SyncDB
    SetRejected --> SyncDB
    
    SyncDB --> EndTriage([End: Scheduling Complete])

Emergency & Broadcast Notification

Flowchart tracing broadcasts distribution to log archiving and cleanup.

flowchart TD
    StartAdmin([Admin accesses Settings]) --> WriteNotice[Compose Broadcast Announcement]
    WriteNotice --> SelectAudience{Select Target Audience}
    
    SelectAudience -- "Outpatients" --> BroadcastPatient[Broadcast to Patient Inbox]
    SelectAudience -- "Clinicians" --> BroadcastStaff[Broadcast to Staff Inbox]
    SelectAudience -- "All" --> BroadcastAll[Broadcast to All Terminals]
    
    BroadcastPatient --> WriteLog[Write to System Audit Logger Engine]
    BroadcastStaff --> WriteLog
    BroadcastAll --> WriteLog
    
    WriteLog --> ViewHistory[Log rendered in Broadcast History List]
    ViewHistory --> ManageLogs{Admin Decision: Delete Log?}
    
    ManageLogs -- "No" --> EndLogs([End: Announcement Retained])
    ManageLogs -- "Yes" --> RequestDelete[Trigger DELETE API /api/logs/:id]
    RequestDelete --> RemoveDb[Delete from database & Refresh View]
    RemoveDb --> EndLogs
